# Amit OS Welcome App

A GTK3 based welcome application for Amit OS that launches on first boot.

## Features
* **Getting Started**: Information and system update shortcuts.
* **AmitShield Security**: Information about Amit OS's built-in security features.
* **Customization**: Shortcuts to Amit OS Control Panel.

## Usage
Run the application using Python 3:
```bash
python3 amit-welcome.py
```
