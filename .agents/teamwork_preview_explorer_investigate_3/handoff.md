## 2. Logic Chain

1. **Theme Overwrite**: Because hooks are executed in lexicographical order, `0100-amitos-setup.hook.chroot` runs before `0400-branding.hook.chroot`. Since `0400` uses `cat >` (which overwrites the entire target file), all dark-theme and usability preferences written by `0100` are deleted. This leaves the system in Breeze Light theme and overrides user accessibility choices.
2. **Missing `g++` compiler**: The `0400-branding.hook.chroot` tries to run `g++` to compile `amitshield_core.cpp`. If `g++` is not present in the package list (as in the repository `amitos.list.chroot` utilized by `build.sh`), execution fails with exit code 127. Under `set -e`, this aborts the build.
3. **Missing `--archive-areas`**: When `live-build` runs `lb config` without specifying `--archive-areas "main contrib non-free non-free-firmware"`, it configures the chroot apt with only `main`. As a result, non-free firmware, microcodes, and contrib packages cannot be resolved, causing apt failure and aborting the build.
4. **Unensured Symlink Directory**: If `/usr/share/wallpapers/Next/contents/images/` does not exist during chroot building, the `ln -sf` command in the branding hook will fail. Under `set -e`, this aborts the build.
5. **`/dev/null` and `mknod`**: Deleting `/dev/null` inside the chroot can corrupt the host's `/dev/null` if `/dev` is bind-mounted. Re-creating it with `mknod` requires `CAP_MKNOD` privileges, which are missing in containerized/restricted WSL2 environments. If `mknod` fails, it has no `|| true` handler, which aborts the build.
6. **`amittray` Autostart**: Because `make_desktop` is never called for `amittray`, `$DESK/amittray.desktop` does not exist. The `cp` command silences errors and continues, but the autostart link is missing, preventing `amittray` from launching on boot.

## 3. Caveats

- We assume that the target build environment runs in a root-privileged shell inside WSL2 or native Linux.
- We did not perform live compilation tests due to read-only investigation constraints.
- We assume that package repositories are reachable and that local DNS is working as configured in the scripts.

## 4. Conclusion

The existing hook scripts and package lists contain **several build-breaking and functional bugs**. To ensure a clean, reliable offline build with the correct dark theme layout, these configurations must be unified and corrected.

### Proposed Code Changes

#### Fix 1: Unified `kdeglobals` and directory check in `0400-branding.hook.chroot`
Remove the `kdeglobals` writing from `0100-amitos-setup.hook.chroot`, and update `0400-branding.hook.chroot` to write a fully unified version and create the wallpaper directory:

```bash
# In config/hooks/normal/0400-branding.hook.chroot
# (Replace lines 37-48 with the following unified block)
cat > "$SKEL/kdeglobals" << 'EOF'
[General]
ColorScheme=BreezeDark
font=Inter,10,-1,5,50,0,0,0,0,0
fixed=Hack,10,-1,5,50,0,0,0,0,0
smallestReadableFont=Inter,8,-1,5,50,0,0,0,0,0
toolBarFont=Inter,10,-1,5,50,0,0,0,0,0
menuFont=Inter,10,-1,5,50,0,0,0,0,0

[Icons]
Theme=breeze-dark

[KDE]
LookAndFeelPackage=org.kde.breezedark.desktop
SingleClick=false
AnimationDurationFactor=0.5
EOF

# Ensure wallpaper destination directory exists before symlinking (Line 76)
mkdir -p /usr/share/wallpapers/Next/contents/images/
ln -sf "$BRANDING_DIR/wallpaper.png" /usr/share/wallpapers/Next/contents/images/1920x1080.png
```

#### Fix 2: Enable `--archive-areas` in all build scripts
Modify `lb config` in `build/build.sh`, `build/wsl-build.sh`, and `build/prepare-offline.sh` to include the non-free components:
```bash
lb config --mode debian \
    --distribution bookworm \
    --archive-areas "main contrib non-free non-free-firmware" \
    ...
```

#### Fix 3: Add missing `g++` package
Add `g++` to the compiler utilities section of `config/package-lists/amitos.list.chroot`.

#### Fix 4: Fix `9999-super-fix.hook.chroot`
Avoid deleting `/dev/null` or add safe fallbacks:
```bash
# Safe recreation only if missing
if [ ! -e /dev/null ]; then
    mknod -m 666 /dev/null c 1 3 || true
fi
```

#### Fix 5: Generate `amittray.desktop`
Add the missing desktop shortcut generation to `config/hooks/normal/0200-amit-apps.hook.chroot`:
```bash
make_desktop "amittray"    "AmitTray"     "System Tray Utilities" "preferences-desktop-notification" "Utility"
```

## 5. Verification Method

To independently verify these issues and their fixes:
1. **Theme Verification**: Inspect the built ISO image or live environment config at `/etc/skel/.config/kdeglobals`. If the file is missing `ColorScheme=BreezeDark`, the bug is present.
2. **Build Verification**: Run `./build/build.sh` (or `build.sh` inside the chroot). If it crashes during `0400-branding.hook.chroot` on `g++` or `ln -sf`, the bugs are verified.
3. **Apt Resolution Verification**: Run `lb config` and `lb chroot` without `--archive-areas`. If it returns `E: Unable to locate package intel-microcode`, the missing component bug is verified.
